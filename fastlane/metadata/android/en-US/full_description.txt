Installs and updates the following browsers:

Browsers from Mozilla or based on Firefox:
- Fennec F-Droid
- Firefox Browser, Firefox for Android Beta, Firefox Nightly
- Iceraven
- Tor Browser, Tor Browser Alpha
- Thunderbird for Android, Thunderbird for Android Beta
- WebLibre

Browsers which are better than Google Chrome:
- Cromite
- Chromium
- DuckDuckGo Browser
- Vivaldi
- Vanadium (GrapheneOS's hardened Chromium; the required TrichromeLibrary component is installed
  automatically alongside it)

Other applications:
- FairEmail
- K-9 Mail
- Orbot

JDupdater checks for updates in the background and downloads them as well. On Android 12+ or root devices, JDupdater can also update the apps without user interaction.

This is a personal fork of Tobi823/ffupdater, not published on F-Droid or affiliated with the upstream project. See https://github.com/Jdont9/ffupdater_JD for more information and to download releases.
